
# Enhanced Face and Eye Detection Using OpenCV

## Project Overview
This project detects human faces and eyes from images using
Python, OpenCV, and pretrained Haar Cascade classifiers.
A Streamlit interface allows users to upload a photo or
capture one using their browser camera.

## Features
- Face detection using Haar Cascades
- Eye detection within detected faces
- Image upload and camera capture
- Face and eye detection counts
- Visual results with colored bounding boxes

## Technologies Used
- Python
- OpenCV
- Haar Cascade Classifiers
- Streamlit
- NumPy
- Pillow

## Run Locally
1. Install Python.
2. Install the dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## Limitations
Detection accuracy depends on lighting, image quality,
face orientation, and the Haar Cascade classifiers.
